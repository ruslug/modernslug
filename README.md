# modernslug
Official website of RUSLUG

## Purpose
This repository supersedes the previous site used by the Rutgers University
Student Linux User Group, [Neoslug](https://github.com/di-gital/neoslug).
While Neoslug was a recreation of [the site used by SLUG in 2001](https://web.archive.org/web/20011211091414/http://ruslug.rutgers.edu/),
modernslug is a modernization written in React.

Neoslug will continue to be available at https://ruslug.org/neoslug.
